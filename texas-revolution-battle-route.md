# Texas Revolution Battle Route

This project maps major battle sites from the Texas Revolution and connects them into a route through Texas.

## Project Description

The purpose of this project was to create a route connecting important locations associated with the Texas Revolution. The map provides a visual representation of where major events occurred and how the sites are distributed across Texas.

# Hydrologic Analysis

This project uses GIS to analyze watershed and drainage patterns in West Texas.

## Project Description

The purpose of this project was to perform a hydrologic analysis using elevation data. GIS tools were used to analyze terrain and identify watershed and drainage patterns within the study area.
